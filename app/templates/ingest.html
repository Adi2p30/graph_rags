Ingest books → build graph

Fetches public-domain books from Project Gutenberg per topic, structure-aware chunks them, embeds (dense + TF-IDF sparse), writes Neo4j + Qdrant, then optionally runs the LLM connection-finder. Gutenberg's corpus is pre-1929, so some modern topics may come back with no hits — the run report tells you which.
